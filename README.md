# 🛒 PHP E-commerce

Ceci est mon tout premier projet de site e-commerce, développé en **2021** avec **PHP** et **MySQL**. Il comprend un système d'authentification, un **dashboard admin** et la gestion des produits.

## 🚀 Technologies utilisées
- **PHP** et **HTML/CSS** pour la partie frontend et backend.
- **MySQL** pour la gestion de la base de données.
- **Apache** via **XAMPP** pour héberger l'application localement.

## 🎯 Ce que j’ai appris  
Ce projet m’a permis de découvrir :
- Les bases du **développement backend** avec PHP.
- La gestion d'une **base de données relationnelle** avec MySQL.
- L’utilisation de **XAMPP** et **Apache** pour héberger une application localement.
- La mise en place d'un **dashboard admin** et d'un système d'authentification pour gérer les utilisateurs et les produits.

🚀 Ce fut une première expérience enrichissante dans le développement web.
