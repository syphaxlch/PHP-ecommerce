## 🧩 Prerequisites
Before running the project, make sure you have the following installed on your system:

- [**XAMPP**](https://www.apachefriends.org/index.html) (includes Apache & MySQL)  
- **PHP 7.x** or higher  
- **Web browser** (Chrome, Firefox, Edge, etc.)  
- Optional: **Text editor** such as VS Code or Sublime Text

## 💻 How to Run Locally

Follow these steps to set up the project on your local machine:

1. **Download or clone the repository**  
   - Go to [this link](https://github.com/syphaxlch/PHP-ecommerce)  
   - Click on the green **Code** button and choose **Download ZIP**, then extract it.  
   - Or copy the repository URL and clone it using your preferred method.

2. **Move the project**  
   - Place the extracted folder inside your **XAMPP/htdocs** directory.

3. **Start Apache and MySQL**  
   - Open the **XAMPP Control Panel** and start both **Apache** and **MySQL**.

4. **Create the database**  
   - Open [phpMyAdmin](http://localhost/phpmyadmin)  
   - Create a new database (for example: `ecommerce_db`)  
   - Import the file named `database.sql` included in the project.

5. **Configure database connection**  
   - Open the file `config.php`  
   - Update your MySQL credentials if needed (default: user `root`, no password).

6. **Run the project**  
   - Open your browser and go to:  
     `http://localhost/`

The e-commerce website should now be running locally!
